## 1. Why this task exists ?

Lớp Bronze (Raw Data Ingestion) là nền tảng khởi đầu của kiến trúc Medallion Lakehouse trong nền tảng ACDP. Việc lựa chọn giải pháp lưu trữ đối tượng (Object Storage) và định dạng bảng mở (Open Table Format) đóng vai trò quyết định đến:
1. **Khả năng mở rộng dung lượng và xử lý bài toán "Small-File Problem"**: Thu thập hàng chục nghìn trang web tạo ra lượng lớn file HTML (<100KB) và JSON metadata, dễ làm suy kiệt inode và IOPS của hệ thống lưu trữ truyền thống.
2. **Tính toàn vẹn dữ liệu, khả năng ACID transactions và time-travel**: Đảm bảo dữ liệu thô là bất biến (append-only) và có thể tái lập vết (replayability) khi kiểm thử các mô hình trích xuất LLM ở tầng Silver.
3. **Kỷ luật tài nguyên thực tế (Zero-JVM & 16GB RAM Constraint)**: Phù hợp tuyệt đối với môi trường máy trạm cá nhân 16GB RAM và máy chủ Docker Compose đơn lẻ mà không cần cài đặt cụm Apache Spark/Hadoop cồng kềnh.

## 2. What should I do ?

### Phương Pháp Luận Nghiên Cứu (Methodology)
1. **Khảo sát toàn diện công nghệ khả dụng (Cập nhật 2026)**: Khảo sát khách quan các giải pháp Object Storage (*Local POSIX, SeaweedFS, MinIO, Cloudflare R2, AWS S3*) và Open Table Formats (*Delta Lake, Apache Iceberg, Lance, Apache Hudi, Raw Parquet+Manifest*).
2. **Cơ sở khoa học hàn lâm (Top-tier Conferences 2024-2026)**: Kế thừa chuẩn mực từ **SIGMOD 2024 LST-Bench**, **VLDB 2025 Ursa**, **SIGMOD 2026 PTO**, **CIDR 2023 LHBench**, **OSDI 2010 Haystack** và **ISO 28500:2017 (WARC)**.
3. **Phân tích ưu - nhược điểm (Pros & Cons) và ma trận định lượng**: Đánh giá trên 10 tiêu chí: tốc độ ghi nạp, chi phí siêu dữ liệu file nhỏ, chi phí nén (compaction), độ trễ truy vấn DuckDB 1.2+, và mức trần tiêu thụ RAM.
4. **Xác định lộ trình chuyển đổi (Migration Triggers)**: Kết luận công cụ tối ưu cho từng giai đoạn phát triển của đồ án.

## 3. Tóm Tắt Kết Quả Nghiên Cứu & Đề Xuất Kỹ Thuật

| Hạng Mục | Đề Xuất Giai Đoạn 1 (MVP / Dev < 50k Cuộc Thi) | Đề Xuất Giai Đoạn 2 (Scale-Out Toàn Quốc > 50k Cuộc Thi) | Rationale & Cơ Sở Khoa Học |
| :--- | :--- | :--- | :--- |
| **Object Storage** | **Local NVMe POSIX** (trừu tượng qua Storage Interface) | **SeaweedFS** (Docker) hoặc **Cloudflare R2** (Cloud) | SeaweedFS tối ưu đọc/ghi O(1) file nhỏ theo chuẩn Facebook Haystack (OSDI 2010), RAM < 150MB; Cloudflare R2 Zero-Egress miễn phí băng thông tải ra. MinIO bị loại vì AGPLv3 và ngốn 1–2GB RAM. |
| **Open Table Format** | **Delta Lake (`delta-rs` / Rust)** | **Delta Lake + Delta UniForm / Apache XTable** | Thư viện `delta-rs` (0.25+) viết bằng Rust chạy in-process trong Python, Zero-JVM, hỗ trợ `OPTIMIZE` bin-packing nén file về 128MB. Tự động sinh metadata Apache Iceberg qua UniForm/XTable (2026). |
| **Đóng Gói Raw Data** | **Embedded Binary Column** (`raw_html_bytes` Zstandard) | **WARC (ISO 28500)** hoặc Delta Table | Triệt tiêu hoàn toàn bài toán phân mảnh file nhỏ; gom toàn bộ dữ liệu trang web vào khối Parquet có giao dịch ACID. |
