# ACDP Implementation Roadmap: 15-Week Special Topic Project (TLCN MVP)

This roadmap outlines the milestones for the **Special Topic Project (Tiểu luận chuyên ngành)** leading up to the final defense in December 2026.

---

## Milestone Schedule

| Phase | Duration | Focus Area | Key Deliverables | Status |
| :--- | :---: | :--- | :--- | :---: |
| **M1: Foundation & Governance** | Weeks 1–3 | Architecture, specifications, and repository harness | Proposal, Thesis Registration, ADR-0001, SPEC-0001, Agent Harness | ✅ Completed |
| **M2: Data Ingestion Engine** | Weeks 4–5 | Crawling 5–10 key sources with Crawl4AI & Playwright | Automated crawlers, LLM Schema Parser, Raw Bronze layer | ⏳ Upcoming |
| **M3: Lakehouse & Quality** | Weeks 6–7 | DuckDB, Parquet, and dbt deduplication & normalization | Silver & Gold layer pipelines, data quality test suites | ⏳ Planned |
| **M4: RAG Regulation Engine** | Weeks 8–10 | Qdrant vector storage, BM25 Hybrid Search, Cross-Encoder | Rulebook chunking, RAG evaluation, hallucination controls | ⏳ Planned |
| **M5: Serving & Web Portal** | Weeks 11–13 | FastAPI backend endpoints and Next.js 15 student portal | Interactive competition explorer, chat assistant, admin BI | ⏳ Planned |
| **M6: Testing & Final Defense** | Weeks 14–15 | End-to-end integration, full academic report, slide deck | Final thesis manuscript, system demonstration, committee defense | ⏳ Planned |
