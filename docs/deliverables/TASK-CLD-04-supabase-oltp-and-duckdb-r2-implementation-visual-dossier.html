2. Các bước thủ công gắn Supabase Shared Pooler vào `.env`
  1. Tạo project miễn phí trên Supabase Dashboard (Region: Singapore ap-southeast-1).
  2. Bấm Connect → Connection String → URI, bỏ qua dòng Direct connection (chỉ IPv6) và cuộn xuống mục Shared Pooler (aws-*-ap-southeast-1.pooler.supabase.com:5432 hoặc :6543).
  3. Sao chép URI, thay mật khẩu DB và dán vào SUPABASE_DATABASE_URL= trong .env.
  4. Khởi chạy API: uv run uvicorn acdp.api.main:app --port 8000 để tự động khởi tạo 5 bảng OLTP trên Supabase.
  5. Chạy kiểm thử tích hợp: uv run pytest tests/api/ tests/test_infra_spec0006.py -v (đã kiểm chứng thực tế 12/12 PASSED).
