uv run python -m acdp.v2.gold_star_schema --metabase-sql

# 2. Bật tạm Metabase Local (:3001) khi demo Hội đồng hoặc offline backup
docker compose --profile bi up -d metabase

# 3. Tắt Metabase sau khi xong để giải phóng ~650–850 MB JVM RAM
docker compose --profile bi stop metabase
-- Kiểm định Bất biến Bảo toàn Tổng Giải thưởng (0.0 VND drift)
WITH kpi_sum AS (SELECT SUM(total_prize_vnd) AS fact_total_vnd FROM fact_competitions),
     dom_sum AS (SELECT SUM(allocated_prize_vnd) AS bridge_total_vnd FROM mart_domain_analytics)
SELECT fact_total_vnd, bridge_total_vnd, ABS(fact_total_vnd - bridge_total_vnd) AS drift_vnd
FROM kpi_sum, dom_sum;
6. Ngân hàng Phản biện Hội đồng & Nguồn Tham khảo (DIR-020)

Q1: Tại sao không nhúng iframe Metabase lên Web? Vì iframe phá vỡ giao diện Tailwind v4 Dark/Light mode, không điều hướng được sang luồng OLTP ghép đội, và Metabase Cloud không có gói Free (từ $100/tháng).

Q2: Khi lên Cloud Free Tier, Metabase chạy ở đâu? Không triển khai Metabase lên Cloud; chuyển hoàn toàn ad-hoc SQL & DataOps sang MotherDuck Lite Free ($0/tháng, 10 GB, 10h Pulse). Metabase Docker chỉ giữ ở --profile bi cho demo local.

Nguồn kiểm chứng 2026: metabase.com/pricing, metabase.com/docs (Docker & JVM -Xmx), motherduck.com/pricing (Lite 10 GB / 10h), motherduck.com/docs/integrations/cloud-storage/amazon-s3, github.com/motherduckdb/metabase_duckdb_driver, prefect.io/pricing.
