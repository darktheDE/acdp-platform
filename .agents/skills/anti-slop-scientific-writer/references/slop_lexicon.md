# Slop Lexicon: Banned AI Vocabulary & Scientific Alternatives

> **Repository**: `acdp-platform`  
> **Applicable Agents**: Antigravity, Claude Code, Gemini CLI, Cursor, Windsurf  
> **Scope**: English & Vietnamese technical reports, theses, research proposals, Markdown, HTML, and chat responses.

---

## 1. English Banned Lexicon (AI Slop Words)

### 1.1. Ornate & Grandiose Nouns
| Banned AI Word | Problem / Connotation | Scientific & Engineering Alternatives |
| :--- | :--- | :--- |
| **tapestry** | Empty visual metaphor for anything interconnected. | *system, interconnected architecture, network, framework, synthesis* |
| **landscape** | Cliché filler noun for any domain, sector, or field. | *domain, field, application area, technical sector, environment* |
| **testament** | Grandiose theological/historical claim without quantitative basis. | *evidence, empirical demonstration, proof, confirmation, indicator* |
| **beacon** | Melodramatic moral metaphor. | *benchmark, baseline, reference standard, model* |
| **paradigm** | Buzzword used to inflate ordinary software components. | *model, architecture, pattern, methodology, design* |
| **synergy** | Corporate boardroom cliché with zero scientific precision. | *interaction, combined performance, integration, joint effect* |
| **touchstone** | Archaic literary flourish. | *criterion, reference baseline, evaluation metric* |
| **game-changer** | Marketing hyperbole. | *substantial improvement, statistically significant shift* |

### 1.2. Overused Verbs (The "AI Action" Tropes)
| Banned AI Verb | Problem / Connotation | Scientific & Engineering Alternatives |
| :--- | :--- | :--- |
| **delve (into)** | Number 1 hallmark of ChatGPT/Claude output. | *examine, investigate, analyze, evaluate, study, inspect* |
| **embark (on)** | False narrative journey metaphor. | *begin, start, initiate, deploy, execute* |
| **foster** | Vague maternal metaphor. | *facilitate, support, enable, produce, cultivate* |
| **elevate** | Marketing pitch word. | *increase, improve, heighten, upgrade* |
| **streamline** | Vague efficiency claim without metrics. | *simplify, optimize, reduce complexity, accelerate* |
| **harness** | Cliché for using basic tools. | *apply, utilize, employ, execute, run* |
| **revolutionize** | Inflated historical claim. | *alter, transform, advance, modernize* |
| **demystify / unravel** | Condescending teacher voice. | *explain, clarify, formalize, describe* |
| **underscore** | Overused transition verb. | *emphasize, highlight, indicate, confirm* |

### 1.3. Empty Adjectives & Dramatic Adverbs
| Banned Term | Problem / Connotation | Scientific & Engineering Alternatives |
| :--- | :--- | :--- |
| **crucial / vital** | Over-intensifier used on routine features. | *necessary, required, central, key* |
| **paramount / pivotal**| Exaggerated importance. | *primary, principal, decisive, essential* |
| **robust** | Thrown at everything without error bounds or stress tests. | *resilient, fault-tolerant, verified (specify p99 / unit tests)* |
| **seamless** | Marketing buzzword. Systems always have interfaces/latency. | *integrated, continuous, low-latency, automated* |
| **groundbreaking** | Inflated self-congratulation. | *novel, initial, first-order, empirical* |
| **multifaceted** | Fluff word avoiding concrete detail. | *having multiple components/stages (name them specifically)* |
| **quietly** | Magical adverb used to inject artificial intrigue. | *Delete the adverb or describe the exact technical mechanism.* |
| **fundamentally** | False profundity. | *Delete or explain specific algorithmic/mathematical root cause.* |
| **deeply** | Emotional intensifier. | *Delete or provide quantitative magnitude.* |
| **arguably** | Hedging without taking a stance or citing sources. | *State evidence or citation directly, or omit claim.* |

## 2. Vietnamese Banned Lexicon (Từ Ngữ Sáo Rỗng Tiếng Việt)

| Cụm từ AI Slop | Vấn đề trong văn phong khoa học | Cách diễn đạt chuẩn mực khoa học |
| :--- | :--- | :--- |
| **đi sâu vào** | Dịch thô từ "delve into", sáo rỗng. | *khảo sát, phân tích, đánh giá, kiểm thử thực nghiệm* |
| **bức tranh toàn cảnh** | Dịch thô từ "landscape", chung chung. | *tổng quan bối cảnh, phạm vi nghiên cứu, kiến trúc tổng thể* |
| **minh chứng cho** | Cường điệu hóa, dịch từ "testament". | *bằng chứng thực nghiệm, kết quả đo đạc cho thấy* |
| **ngọn hải đăng** | Ẩn dụ văn học không phù hợp kỹ thuật. | *mô hình chuẩn, hệ thống đối sánh (benchmark)* |
| **hành trình** | Nhân cách hóa quy trình kỹ thuật. | *chu kỳ thực thi, tiến trình, vòng đời dữ liệu* |
| **bước ngoặt** | Cường điệu hóa tác vụ thông thường. | *cải tiến kỹ thuật, điểm chuyển đổi kiến trúc* |
| **đóng vai trò then chốt/quan trọng** | Điệp từ rỗng, thiếu định lượng. | *quyết định, cần thiết đối với, ảnh hưởng trực tiếp đến* |
| **giải pháp toàn diện** | Khẩu hiệu quảng cáo, thiếu ranh giới. | *kiến trúc tích hợp (nêu rõ các module cụ thể)* |
| **vượt trội / tối ưu hóa vượt bậc** | Tuyên bố định tính thiếu căn cứ số liệu. | *cải thiện 35% throughput, giảm 120ms latency* |
| **hãy cùng tôi khám phá** | Giọng điệu hướng dẫn viên, không chuyên nghiệp. | *Xóa bỏ; bắt đầu ngay bằng phân tích kỹ thuật* |
| **chắc chắn rồi / tuyệt vời** | Xã giao nịnh bợ, tiêu tốn token. | *Xóa bỏ hoàn toàn; trả lời trực diện vào câu hỏi* |
| **như chúng ta đã biết** | Mượn sự đồng thuận giả định (Appeal to familiarity). | *Xóa bỏ; trích dẫn nguồn hoặc số liệu cụ thể* |
| **đáng chú ý là / thú vị là** | Từ đệm kịch tính hóa giả tạo. | *Xóa bỏ; trình bày sự kiện một cách khách quan* |
| **không thể phủ nhận rằng** | Từ đệm áp đặt định kiến. | *Xóa bỏ; để số liệu tự chứng minh* |
| **mảnh ghép quan trọng** | Ẩn dụ lắp ghép văn học. | *thành phần, module chức năng, tham số đầu vào* |

## 3. General Replacement Rules (Nguyên Tắc Thay Thế Tổng Quát)

1. **Quantify or Cut (Định lượng hoặc Loại bỏ)**:
   - Nếu một tính từ không thể đo đạc bằng số liệu cụ thể (ví dụ *"rất mạnh"*, *"vượt bậc"*), hãy xóa bỏ nó hoặc thay thế bằng thông số đo đạc thực tế (ví dụ *"đạt 1.450 QPS với p95 < 80ms"*).
2. **Action-Verb Primacy (Ưu tiên Động từ Hành động Thực tế)**:
   - Thay vì viết *"hệ thống tận dụng khả năng của DuckDB để đẩy mạnh hiệu năng"*, hãy viết trực tiếp: *"hệ thống thực thi truy vấn SQL qua engine DuckDB trên tệp Parquet"*.
3. **No Hedging Without Data (Không rào đón thiếu bằng chứng)**:
   - Tránh dùng *"có thể xem như"*, *"dường như"*, *"arguably"* trừ khi đang thảo luận về khoảng tin cậy thống kê (confidence interval).
